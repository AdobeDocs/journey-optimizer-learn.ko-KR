# 외부 대상자와 여정 시뮬레이션

{{limited-availability}}

티켓 ID 또는 여행 날짜와 같이 프로필에 저장되지 않은 특성을 포함하여 CSV 파일 또는 통합 대상 구성에서 외부 대상 프로필을 사용하는 여정을 시뮬레이션하는 방법을 알아봅니다. 이 비디오는 대상을 필터링하고, 외부 속성을 사용하여 메시지를 개인화하고, 시뮬레이션된 사용자를 만들고, 여정이 라이브로 전환되기 전에 올바른 경로를 확인하기 위해 대상 데이터를 조롱하는 과정을 안내합니다.
