# 경고 사용

예기치 않은 여정 동작에 대해 사전 정의된 경고를 구독하고 이메일을 통해, Journey Optimizer 내에서 또는 API를 사용하여 알림을 받는 방법에 대해 알아봅니다.

>[!NOTE]
>
>이 비디오에서는 Adobe Experience Platform 사용자 인터페이스의 경고 기능을 보여줍니다. 이 기능은 Journey Optimizer의 왼쪽 탐색 메뉴인 [관리] > [경고]에서 액세스할 수 있습니다.
>
>
>Journey Optimizer에서 경고에 액세스할 때는 기본적으로 라이브 여정에 관련된 경고만 표시됩니다.
