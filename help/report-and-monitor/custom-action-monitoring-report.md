# 사용자 정의 액션 모니터링

사용자 정의 액션을 통해 여정에서 서드파티 엔드포인트로 전송되는 HTTP 호출의 작동 상태 및 성능을 효과적으로 모니터링하는 방법을 알아봅니다. 게재에 영향을 미칠 수 있는 HTTP 오류, 지연 병목 현상, 캡핑 문제에 대한 가시성을 확보합니다.

이 보고서는 문제를 식별하고 여정의 성능을 향상시키며 여정이 원활하게 작동하도록 하는 데 도움이 됩니다.
